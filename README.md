# LuaU-AIDS — Luau AI Dataset for Synthetic Instruction Tuning

All data are generated by AI and filtered.

## Overview

A high-density, production-oriented synthetic instruction-tuning dataset for training language models to design, debug, optimize, and implement modern Roblox systems using Luau.

Each dataset entry teaches transferable engineering principles across:
- Server-authoritative game architecture
- Network security and RemoteEvent validation
- Type safety with `--!strict` Luau
- Performance engineering and memory management
- Roblox API correctness

## Dataset Format

**File:** `dataset.jsonl`

Each line is a valid JSON object with the structure:

```json
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."},
    {"role": "analysis", "content": "..."},
    {"role": "assistant", "content": "..."}
  ]
}
```

- **system** — Standard expert Luau engineer identity
- **user** — Realistic Roblox engineering problem with constraints
- **analysis** — Concise architectural rationale and design decisions
- **assistant** — Complete, production-ready Luau implementation
