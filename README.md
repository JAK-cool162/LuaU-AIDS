# LuaU-AIDS — Luau AI Dataset for Synthetic Instruction Tuning

All data are generated by AI and filtered.

## Overview

A high-density, production-oriented synthetic instruction-tuning dataset for training language models to design, debug, optimize, and implement modern Roblox systems using Luau.

**1000 entries** — each teaching transferable engineering principles across:
- Server-authoritative game architecture
- Network security and RemoteEvent validation
- Type safety with `--!strict` Luau
- Performance engineering and memory management
- Roblox API correctness
- Clean, professional code formatting

## Dataset Format

**File:** `dataset.jsonl` (~4.5 MB, 1000 entries)

Each line is a valid JSON object:

```json
{
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."},
    {"role": "analysis", "content": "..."},
    {"role": "assistant", "content": "..."}
  ]
}
```

## Module Coverage

The dataset covers 9 core module architectures with multiple variants each:

| Module | Type | Description |
|--------|------|-------------|
| **Signal** | Shared | Type-safe event system with Connect/Once/Fire/Wait |
| **Maid** | Shared | Deterministic cleanup manager for connections and instances |
| **Timer** | Shared | Frame-rate independent timer with callbacks |
| **ObjectPool** | Shared | Reusable instance pooling with pre-allocation |
| **SpatialGrid** | Shared | O(1) spatial partitioning for proximity queries |
| **RateLimiter** | Server | Token bucket rate limiting per player |
| **CooldownSystem** | Server | Per-player cooldown tracking with os.clock() |
| **HealthSystem** | Server | Health, shields, invulnerability, damage events |
| **Inventory** | Server | Stack-based item storage with capacity limits |

## Game Genres Covered

Competitive multiplayer, battle royale, RPG, tower defense, racing, survival, fighting game, MMO dungeon, horror, sandbox, obstacle course, capture the flag, arena shooter, roguelike, party game, pet simulator, tycoon, escape room, battle arena, and zombie survival.

## Code Quality Standards

All generated Luau follows:
- `--!strict` mode in every entry
- 4-space indentation consistently
- Section header comments with visual dividers
- Full type annotations (export type, typed parameters, typed returns)
- Modern Roblox APIs only (no `wait()`, `spawn()`, `delay()`, `:connect()`)
- Server-authoritative design patterns
- Memory-safe connection lifecycle management
- Comprehensive input validation and rate limiting
