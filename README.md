# LuaU-AIDS — Luau AI Dataset for Synthetic Instruction Tuning

All data are generated by AI and filtered.

## Overview

A high-density, production-oriented synthetic instruction-tuning dataset for training language models to design, debug, optimize, and implement modern Roblox systems using Luau.

**1,000 entries** with **15 unique, production-quality Luau code modules** — each appearing across ~50 different query contexts and game genres.

## Dataset

**File:** `dataset.jsonl` — 1,000 entries, ~3.9 MB

Each line is a valid JSON object with 4 messages (system, user, analysis, assistant).

## Code Quality

- `--!strict` in every entry
- Consistent 4-space indentation
- Visual section dividers (`──────`)
- Full `export type` with method signatures
- Descriptive variable names
- No deprecated APIs (`wait()`, `spawn()`, `delay()`)
- Server-authoritative design
- Memory-safe cleanup (PlayerRemoving, Destroy, Maid patterns)
- os.clock() for all timing (not tick counting)
